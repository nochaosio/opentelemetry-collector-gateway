# Code of Conduct

This project follows the
[CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md),
the same one the OpenTelemetry projects use.

Report unacceptable behavior privately to the maintainers listed in
[.github/CODEOWNERS](.github/CODEOWNERS), through their GitHub profiles.
Reports are handled confidentially.
